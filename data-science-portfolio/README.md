# data-science-portfolio

My personal data science portfolio website, published with **GitHub Pages**.

- Live site: [https://mc65187.github.io/data-science-portfolio/](https://mc65187.github.io/data-science-portfolio/)
- Project repository: [github.com/mc65187/data-science-project](https://github.com/mc65187/data-science-project)

The site is generated from `index.md` in the repository root. To update it,
edit `index.md` (or the images in `images/`) and push to the `main` branch —
GitHub Pages rebuilds automatically.
